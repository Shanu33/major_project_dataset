## 📊 Summary Metrics

- **Gold Projects (5)**: Ready for end-to-end quantity and cost prototype modeling (full drawings + BOQs + specs + costs).
- **Silver Projects (15)**: High-value official packages with one or two specific post-award engineering deliverables pending.
- **Reference Only Projects (9)**: Valuable statutory benchmarks, township charters, or consultancy packages where working GFC drawings or trade BOQs are restricted.
- **Reject Projects (1)**: Formally audited and rejected candidate projects with no public procurement record, preventing training set contamination.
