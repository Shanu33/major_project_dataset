# 03 - Technical Specifications & BIS Standards

Engineering standards governing structural concrete, metallurgy, and finishes:
- Concrete Grade: Minimum M-25 / M-30.
- Steel Grade: Fe 500 / Fe 550D TMT reinforcement per IS 1786.
- Seismic Zone III detailing per IS 1893:2016 and IS 13920:2016.
