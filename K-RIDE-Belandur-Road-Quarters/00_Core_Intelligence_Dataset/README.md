# 00 - Core Intelligence Benchmark Dataset (K-RIDE Railway Residential & Station Infrastructure)

This directory contains the primary benchmark files and core contract specifications for the **Rail Infrastructure Development Company (Karnataka) Limited (K-RIDE)** projects in the Bengaluru suburban and railway corridor, specifically covering **Belandur Road Station & Facilities** and the **Hosur Railway Staff Quarters (Type-II & Type-III)**.
